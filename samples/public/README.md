# Публичные тестовые фиксации

Это настоящий Workspace, созданный browser E2E для example.com, example.org, example.net. Его можно подключить TraceVault как существующую рабочую папку или открыть HTML напрямую без расширения. Скопированы исходные файлы с сохранением байтов; SHA-256 в событиях проверяется относительно этого корня.

Это тестовые материалы, а не результаты расследования. Время записано с системных часов тестовой машины, независимой доверенной метки нет. Персональные данные не использовались. Не добавляйте личные материалы в этот публичный пример; для своей работы выберите другую папку.
