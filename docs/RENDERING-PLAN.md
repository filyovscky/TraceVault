# 0.3.0: полный PNG, производный PDF, знак

Архитектура до реализации, 22.10.2026.

## Ограничения API и решение

Chrome captureVisibleTab снимает только viewport и ограничен двумя вызовами в секунду. Page.captureScreenshot/printToPDF требуют CDP; debugger нельзя запросить optional permission. Расширение не расширяет разрешения: полный PNG строится прокруткой и склейкой кадров через Canvas, PDF формируется из проверенных пикселей PNG. Это растровая конвертация, не печать DOM, не OCR. Runtime-зависимости не добавляются.

Источники: https://developer.chrome.com/docs/extensions/reference/api/tabs ; https://developer.chrome.com/docs/extensions/reference/api/permissions ; https://chromedevtools.github.io/devtools-protocol/tot/Page/ .

## Компоненты и хранение

- screenshot.js: измерение document/viewport, двумерная сетка, фактические scrollX/Y, rate limit, Canvas. Перед/после кадров проверяются URL, активная вкладка, размеры, масштаб. finally возвращает scroll и внешний service восстанавливает аннотации. Автоматическое бесконечное догружание не выполняется; динамический размер означает отказ. Sticky/fixed диагностируются, без редактирования CSS страницы. Снимок не является атомарным.
- pdf.js: A4 с полями и нумерацией, RGB + Flate без потерь, источник/время/хеш PNG в метаданных. Привязка PDF к source_artifact_id/source_sha256, searchable_text=false.
- service.js: прежний Web Lock, очередь/журнал/папка. Сначала отдельные первичные кадры с readback SHA-256, затем stitched PNG, затем опциональный PDF. Каждый файл — отдельный Artifact. Исключение/отмена оставляет честный failed/cancelled с уже записанными кадрами. Завершение только после повторного чтения записанного результата.
- panel.js: «Полный PNG», «Страница в PDF», «Создать PDF» для сохранённого PNG; команды палитры. Статус прогресса/отмена; просмотр/экспорт проверяют SHA-256. Кадры свёрнуты в карточке.
- Совместимость: существующие schema v1 записи не меняются. В разрешённые значения Artifact.kind добавляются full_page_png, screenshot_frame, derived_pdf. Экспорт новых типов требует актуальной схемы; старые строгие валидаторы не обязаны принимать новые enum. Capture.kind остаётся screenshot, детали — capture_scope/capture_request/frames/derivation. Адаптер OSINTchart использует MIME/пути/хеши и проверяется реальными тестами.
- Лимиты: 24 млн итоговых пикселей, сторона до 30000, до 64 кадров, лимит байтов workspace применяется ко всем кадрам и результатам операции. Отказ до allocation при превышении размеров.

## Логотип

Авторский SVG: срезанный угол рамки архива, монограмма T/V, одна фиолетовая заливка и белый знак; без теней/градиентов. PNG 16/32/48/128 из тех же координат для Chrome, SVG в заголовке панели. Генератор Pillow — только build-time, прежняя зависимость. Никаких внешних шрифтов или изображений.
