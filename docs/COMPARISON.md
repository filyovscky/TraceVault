# TraceVault and adjacent tools — 27 October 2026

TraceVault claims below come from this repository and the documented test scenarios. Competitor features below are vendor-published capabilities, not independently verified side-by-side behavior. No competitor memory/CPU tests were run. Plans can limit features. Marketing phrases about court admissibility are not adopted as a guarantee.

| Tool | Published emphasis | Practical difference from TraceVault 0.5.0 |
| --- | --- | --- |
| TraceVault | Local chosen-directory cases, HTML/PNG/raster PDF, SHA-256 readback, separate highlights/notes, source-linked entity drafts, explicit one-window URL journal | Personal research workflow. No automatic preservation of every visited page; the session is metadata only. No OCR, signed PDF report, independent timestamp, video or production-scale journal index. |
| [Forensic OSINT](https://www.forensicosint.com/) | Full rendered-page/source/media capture, expansion of comments, case management and digitally signed PDF evidence reports; additional search and collaboration capabilities depend on plan | A substantially broader forensic/reporting platform. TraceVault's plain raster PDF is not equivalent to their signed evidence report. [Deployment options](https://www.forensicosint.com/cloud-managed) include managed Azure USA, dedicated cloud and on-premise, so it would be incorrect to describe it as cloud-only. |
| [Hunchly](https://hunch.ly/) | Automatic full-page collection with URLs/timestamps/hashes, tags/search, audit trail and reporting; local Classic and cloud options | Closest conceptual comparator for recording an investigation. TraceVault currently tracks the selected window's browsing trail without automatically archiving each page. Local storage alone is not unique to TraceVault. [Classic is listed at USD 169/year](https://hunch.ly/pricing), but cost and feature availability should be checked at purchase. |
| [WebPreserver](https://www.pagefreezer.com/webpreserver/) | Local web/social collection, automatic post/comment expansion, SHA-256/digital signatures, searchable OCR PDF, MHTML and WARC exports | Focused on evidence collection and disclosure. TraceVault does not yet provide OCR, WARC or equivalent signed reporting. No unsupported assertion that WebPreserver necessarily uploads all collected material. |
| [SingleFile](https://www.getsinglefile.com/) | Self-contained offline HTML, selected/all-tab saves, profiles, auto-save, batch URLs and annotation of saved copies; free/open source AGPL | Broader dedicated HTML-archiving functionality than TraceVault's independent best-effort engine; a universal fidelity advantage was not measured. TraceVault adds case-level source links and separate annotations/audit. [SingleFile FAQ](https://github.com/gildas-lormeau/SingleFile/blob/master/faq.md) distinguishes its HTML workflow from professional WARC archiving. TraceVault does not embed its AGPL code. |
| [GoFullPage](https://gofullpage.com/faq) | Full-page screenshots and image/PDF downloads; optional paid editing/cropping/annotation | Appropriate when the actual task is a long screenshot. TraceVault adds case organization, original-file hashes/readback and source-linked notes/entities. We have not established that TraceVault's stitcher is more reliable or faster across arbitrary sites. |

Current useful differentiators are the chosen-folder workflow, live-page highlights saved separately from originals, explicit one-window scope and source-linked entity drafts. They are implementation choices, not evidence that competitors cannot offer similar features. The next highest-value engineering work is capture robustness on complex pages, incremental verified journal indexing, OCR/search and optional independently verifiable timestamp/signature/report outputs. [Measured resource use](PERFORMANCE.md) explains why no blanket “lighter than competitors” claim is justified.
