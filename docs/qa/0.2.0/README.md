# QA 0.2.0 — 22.10.2026

Реальный установленный Chrome 155.0.8059.85. Сохранены 32 PNG: светлая/тёмная темы × ширины 320/360/420/520 CSS px × DPR 1/1.25/1.5/2. Геометрия и физическая ширина PNG проверены автоматически, протокол — native-layouts.json. Визуально просмотрены тёмная 360 px и светлая 320 px/DPR 2: горизонтального обрезания нет, заголовок переносится, действия доступны. Windows scaling отдельно не менялся.

native-side-panel.png снят с настоящего Chrome target, contextType SIDE_PANEL. Палитра в command-palette.png снята браузерным тестом. Сообщение об изменённом файле на фоне палитры — ожидаемый результат теста подмены оригинала, а не фиктивный статус.

Глобальные Ctrl+Shift+3, Ctrl+Shift+1, Ctrl+Shift+2 нажаты через Windows computer-use в отдельном профиле. Открытие панели подтверждено runtime context, HTML и PNG проверены чтением диска и SHA-256. Первая проверка Ctrl+Shift+4 обнаружила неподдержанный whole-paragraph Range; дефект исправлен и покрыт браузерным сценарием. Повторное нативное нажатие после исправления НЕ проверено: computer-use остановлен, поскольку инструмент не смог уверенно определить URL Windows-браузера. Обход остановки не выполнялся.

scripts/keyboard-qa.mjs — интерактивный проверочный стенд с отдельным профилем и настоящей FSA-папкой. Его нужно запускать отдельно от автоматического прогона, нажимая предложенные клавиши в окне «TraceVault Native Keyboard QA». Он не отправляет клавиши самостоятельно; последний полный проход всех четырёх клавиш остаётся ручной задачей.
